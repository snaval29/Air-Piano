# 🎹 Air Piano

A browser-based virtual piano controlled using **hand gestures** in real-time.  
Move your fingertips below the trigger line to play notes — no keyboard needed.

Built using **JavaScript**, **MediaPipe Hands**, **HTML5 Canvas**, and the **Web Audio API** for smooth gesture tracking and dynamic sound synthesis.

---

## 🚀 Features

- ✋ Real-time hand tracking using MediaPipe
- 🎵 Gesture-controlled piano notes
- 🎹 Interactive piano visualization
- 🔊 Dynamic audio synthesis with harmonics + reverb
- 🎼 Multiple musical scales:
  - Chromatic
  - Major
  - Minor
  - Blues
  - Pentatonic
- 👆 Multi-finger note triggering
- 📊 Live hand/finger detection stats
- ⚡ Lightweight and runs directly in the browser

## 🎯 How It Works

1. Enable camera access.
2. MediaPipe detects hand landmarks in real-time.
3. Fingertips crossing the trigger line activate notes.
4. Note positions are mapped based on horizontal finger position.
5. Audio is generated dynamically using oscillators and harmonics.
